# RSS агрегатор

Веб-приложение для чтения RSS-лент в одном месте. Позволяет добавлять новостные источники, просматривать публикации и автоматически получать обновления без перезагрузки страницы.

Учебный проект, выполненный в рамках программы «Фронтенд-разработчик» на Hexlet.

## Возможности

- Добавление RSS-лент по URL.
- Валидация адресов и предотвращение повторного добавления одной ленты.
- Загрузка и разбор RSS в формате XML.
- Отображение списка источников и публикаций.
- Автоматическая проверка новых публикаций каждые 5 секунд.
- Предварительный просмотр публикаций в модальном окне.
- Отметка просмотренных публикаций.
- Обработка ошибок загрузки, некорректных URL и невалидного RSS.
- Сообщения интерфейса на русском языке.

## Технологии

- JavaScript (ES Modules)
- HTML5, CSS3
- Vite — сборка и запуск приложения
- Tailwind CSS — оформление интерфейса

- Yup — валидация

## Запуск локально

Требуются Node.js и npm.

Клонируйте репозиторий:

```bash
git clone https://github.com/Foxtery/frontend-project-11.git
cd frontend-project-11
```

Установите зависимости:

```bash
npm ci
```

Запустите сервер разработки:

```bash
npm run dev
```

Сборка для production:

```bash
npm run build
```

Предпросмотр production-сборки:

```bash
npm run preview
```

Проверка кода линтером:

```bash
npm run lint
```

## Как пользоваться

1. Откройте приложение.
2. Вставьте URL RSS-ленты в поле ввода.
3. Нажмите «Добавить».
4. После успешной загрузки появятся источник и список публикаций.
5. Нажмите «Просмотр», чтобы прочитать краткое содержание публикации, либо перейдите к оригинальной статье.
6. Новые публикации будут подгружаться автоматически.

Для получения RSS-лент приложение использует внешний прокси-сервис AllOrigins от Hexlet.
